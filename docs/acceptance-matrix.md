# Beta acceptance matrix

This matrix maps every specification acceptance scenario to concrete evidence.
Test names identify automated coverage; they are not a claim that the final
candidate suite or a remote workflow has run. Runtime and private columns remain
separate because synthetic execution cannot establish live-source compatibility,
and cross-builds cannot establish target runtime support.

| Specification scenario | Automated evidence | Additional candidate/runtime/private evidence |
| --- | --- | --- |
| Initial five-child check | `TestCandidateFiveEnrolmentWorkload`; `TestStudentsDiscoversFiveChildrenAndKeepsEnrolmentsDistinct`; `TestDiffDoesNotReportExistingRecordsOnFirstSync` | Measure 15 actual requests, five complete coverage entries, explicit baseline, and no events on the final binary. Private acceptance checks selected live source variants; it need not contain five real children. |
| Unchanged second check | `TestCandidateFiveEnrolmentWorkload`; `TestCheckContractScriptedOutcomes` | Measure 20 requests, including five head revalidations, and verify `last_success` advances without consumer progress. |
| New enrolment or selected subset | `TestDiffDoesNotReportHistoryForNewEnrollment`; `TestSeenSourceRecordsSurviveSubsetAndIncompleteChecks`; `TestCheckContractScriptedOutcomes` | Private gate if the selected account has a new/old enrolment or safe subset case; otherwise record `not observed`. |
| Missing family or changed school-year markup | `TestSyncCurrentRejectsMissingExpectedAndNoCurrentEnrolments`; `TestStudentsRejectsPartiallyParsedFamily`; `TestStudentsUsesCurrentIDForActiveLinkWithoutStudentQuery` | Private gate verifies current/old enrolment inference, same-year transfer, and closed enrolment where available. |
| Several pages of new events | `TestProcessCheckCatchesUpPaginatedTimelineAndCommitsState`; `TestTimelineCatchUpCommitsAllPagesThroughOverlap`; `TestTimelineCatchUpDoesNotEmitUnknownSuffixAfterOverlap` | Final candidate workload measures the one-extra-page case as 21 requests. Private pagination is required only for selected live compatibility evidence. |
| No overlap, changing pages, repeated page, or exhausted budget | `TestTimelineCatchUpBoundedIncompletePreservesBaselineAndRetries`; `TestTimelineCatchUpRevalidatesHeadBeforeCompleting`; `TestTimelineCatchUpStopsOnRepeatedPageContent`; `TestTimelineCatchUpRejectsChangingDuplicate`; `TestTimelineCatchUpStopsAtElapsedTimeBound`; `TestCandidateFiveEnrolmentWorkload` | Measure the all-five page-limit result as incomplete after 50 requests and show the last successful baseline survives. |
| Edited note, justified absence, repeated grade, or value changed back | `TestProcessSuccessiveAbsenceCorrectionsRetainDistinctTransitions`; `TestTransitionRevisionSurvivesValueReturningAndRedelivery`; `TestReconcileStableIdentityCarriesBeforeAndAfter`; `TestReconcilePreservesEqualLookingMultiplicityAndAmbiguity` | Private gate records only naturally observed corrections/status changes; unavailable variants stay `not observed`. |
| Overview/feed overlap and feed eviction | `TestReconcileLabelsTimelineAndOverviewSignalsSeparately`; `TestReconcileDoesNotInferFeedOrCurrentListRemoval`; `TestReconcileStableSourceReappearanceUsesKnownIdentity` | Private gate checks an observed overlap/eviction if available and must not infer deletion from absence in the recent feed. |
| Maintenance HTML, success-only JSON, truncated body, or unsupported record | `TestSectionsDistinguishValidEmptyFromUnrecognizedAndUnsupported`; `TestEmptySectionsRejectWrongEnrolmentAndTruncatedContainer`; `TestSubjectsAcceptRecognizedLinkWithoutStudentQuery`; `TestSubjectsRejectInvalidStudentQueryWhenPresent`; `TestSubjectsRejectOmittedStudentQueryInIncompleteOverview`; `TestAbsencesAcceptScopedNoDataMarker`; `TestAbsencesRejectInvalidNoDataMarker`; `TestAbsencesNoDataMarkerStillRejectsWrongEnrolment`; `TestLiveCheckAcceptsVerifiedOverviewAndEmptyAbsenceVariants`; `TestTimelineRejectsSuccessWithoutCoverageMetadata`; `TestTimelineRejectsUnsupportedSymbolValue`; `TestReadResponseBodyRejectsOversizeWithoutReturningPrefix` | Recognized complete overview links may omit the student query, while malformed or conflicting queries still fail. A scoped no-data absence structure is accepted only with its required context. Other private variants remain unverified until selected evidence covers them. |
| Consumer fails, sync runs again, consumer retries | `TestCandidateHeadlessAuthCheckConsumerReplay`; `TestConsumerReplayAcrossCLIProcesses`; `TestConsumerBatchReplayExactAckAndIndependentCursor` | Final process evidence verifies exact batch/token replay and that an acknowledgement cannot consume later events. |
| Two independent consumers and repeated acknowledgement | `TestCandidateHeadlessAuthCheckConsumerReplay`; `TestConsumerReplayRacesActualCLIChecksWithoutPortalReads`; `TestConsumerBatchReplayExactAckAndIndependentCursor` | Final process evidence verifies independent cursors, idempotent acknowledgement, and zero HTTP for local consumer commands. |
| Failure before/at/after commit and before output delivery | `TestGenerationCommitIsAtomicAndRetainsEvents`; `TestKilledProcessBeforeRenameLeavesPriorGeneration`; `TestPostRenameFailureReportsCommittedGeneration`; `TestCommittedCheckSurvivesOutputInterruption`; `TestLiveRetryAfterInterruptedOutputDoesNotDuplicateTransition` | Inspect recovery through `status --profile` on the final binary; no private input is required. |
| Corrupt, foreign-account, or unsupported-version local state | `TestInvalidForeignAndLegacyStateArePreserved`; `TestLoadRejectsEventGapAndPreservesCorruptDocument`; `TestLoadRejectsSemanticallyCorruptCommittedResults`; `TestRecordCheckStatusPreservesUnsupportedExistingState` | Review archive-first migration/recovery commands. Do not mutate the operator's existing state for proof. |
| Simultaneous commands in separate processes | `TestConcurrentCLIProcessesShareAccountRequestPolicy`; `TestProcessesShareBudgetAndRecoverAfterOwnerDeath`; `TestConsumerReplayRacesActualCLIChecksWithoutPortalReads` | Run locking/replay on named macOS and isolated Linux candidates; final evidence must name the environment. |
| Redirects, read retries, and persisted server cooldown | `TestRedirectsAndRetriesEachConsumeBudget`; `TestCooldownAndPacingSurviveProcessExit`; `TestClientRejectsForeignTargetsAndRedirectsBeforeForwardingCookies`; `TestBudgetResetUsesUTCWindowAndClockRollbackDoesNotReset` | Candidate runtime confirms cancellation and shared policy; no live portal refusal is deliberately triggered. |
| Cookie restart, rotation, deletion, scope, and expiry | `TestSessionRoundTripPreservesCookieSemantics`; `TestSessionDeletionExpiryAndBinding`; `TestSessionMaxAgeDoesNotRestartAcrossReload`; `TestLoginPersistsSessionForNextClient`; cookiejar `TestUpdateAndDelete`, `TestExpiration`, `TestDomainHandling` | Named runtime checks restart and expiry recovery with a synthetic portal. Private login evidence is a separate selected gate. |
| Unattended expired session and account switch | `TestCandidateHeadlessAuthCheckConsumerReplay`; `TestRealCLIFailedAuthCheckThenProviderRecovery`; `TestRecoveryUsesCredentialsOnceAndAccountBindingSurvivesReset`; `TestFreshBindingSaveFailureCannotReuseObsoleteSession` | Named macOS/Linux synthetic runtime uses a private synthetic credential file and noninteractive stdin. Live account switch is not required or inferred. |
| Locked/missing provider, password whitespace, or cancelled helper | `TestEnvironmentPreservesPasswordBytesAndRejectsPartialInput`; `TestFileRequiresPrivateModeAndBinding`; `TestFileRejectsSymlinkAndOversizedInput`; `TestKeychainUnattendedFailsBeforeHelper`; `TestCredentialProviderConflictAndCheckErrorReason` | Named runtime checks file permissions, minimal environment, bounded cancellation, and secret-free diagnostics. Real Keychain remains foreground-only. |
| Login redirect to maintenance/503 or unsupported interactive flow | `TestLoginRequiresFreshCredentialsAndRecognizedProtectedPage`; `TestLoginAndReadOverLocalTLS`; `TestRealCLIFailedAuthCheckThenProviderRecovery` | Synthetic runtime verifies no successful binding/session on failure and preserved diary state. A live failure must not be induced. |
| Version-2 upgrade and legacy session reset | `TestCheckRefusesAndPreservesLegacyAccountHistory`; `TestNamespacedLegacyStateRefusesUnboundFiles`; `TestInvalidForeignAndLegacyStateArePreserved`; `TestSessionRejectsLegacyCorruptAndPublicSuffixCookie`; `TestRecoveryUsesCredentialsOnceAndAccountBindingSurvivesReset` | Review migration refusal, archive, new-baseline, and session-reset procedures. Unknown overwritten v2 history stays unknown. |
| macOS and headless Linux execution | Candidate process tests exercise auth, check, locking, cancellation, replay, and restart with synthetic data. CI config targets `macos-15` and `ubuntu-24.04`. | Required evidence is execution on named macOS and isolated Linux runtimes. Cross-builds and syntax-checked CI do not satisfy this row. Actual launchd/systemd/cron execution remains a distinct operator-selected gate. |
| Final local candidate and private acceptance | `go test`, race, vet, module verification, vulnerability scan, four target builds, artifact checksums, and isolated version/install smoke are the required candidate commands. | Record exact source/tool versions and local artifact metadata. The private checklist remains open until selected authorized evidence runs. No remote CI success, publication, operator policy, or legal approval is implied. |

The candidate test helpers set `EDNEVNIK_REQUEST_INTERVAL=0s` and
`EDNEVNIK_MIN_CHECK_INTERVAL=0s` to keep synthetic process tests fast. This does
not change product defaults: 192 requests per UTC calendar day, 2.5-second
pacing, and a 30-minute minimum check interval. Runtime measurements that use
zero pacing prove request counts and state behavior, not default wall-clock
duration.
